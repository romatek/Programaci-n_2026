5. Bucles (for / while), Strings y Errores

  • Bucle for: Cuando sabés cuántas vueltas dar (ej. contar 5 autos).
  • Bucle while: Cuando no sabés cuántas veces; repite mientras se cumpla una condición.
// FOR: Arranca en 1, sigue mientras i <= 5, suma 1 en cada vuelta
for (let i = 1; i <= 5; i++) {
    console.log("Pasó el auto", i);
}

// WHILE: Repite mientras el dato sea inválido
let vel = Number(prompt("Velocidad:"));
while (isNaN(vel) || vel < 0) {
    vel = Number(prompt("Inválido. Velocidad:")); // ¡Vital actualizar!
}

Métodos de Texto (Strings)

  • .length: Cantidad de caracteres.
  • .trim(): Borra espacios al principio y al final.
  • .toUpperCase(): Pasa todo a MAYÚSCULAS.
  • .replaceAll(".", ""): Quita todos los puntos (ideal para limpiar un DNI).

Los 3 tipos de errores

  1. Sintáctico: Código mal escrito (falta una llave). Sale error rojo y no arranca.
  2. Semántico: Se cuelga en ejecución (ej. un while infinito).
  3. Lógico: Anda sin errores, pero da mal el resultado. Se detecta usando console.log() como linterna.
