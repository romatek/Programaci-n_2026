6. Validación de Datos: El Patrón de los 4 Pasos

Un texto se puede recorrer letra por letra usando corchetes, empezando siempre desde la posición 0 (dni[0] es la primera letra).

El flujo universal para validar cualquier dato (DNI, patente, teléfono).
// Técnica "inocente hasta demostrar lo contrario"
let dni = prompt("DNI:").replaceAll(".", "").trim();
let soloDigitos = true;

for (let i = 0; i < dni.length; i++) {
    if (dni[i] < "0" || dni[i] > "9") {
        soloDigitos = false; // Si encontramos UNA sola letra, es inválido
    }
}
