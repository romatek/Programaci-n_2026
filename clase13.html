13. Los 3 Gigantes: map, filter y reduce

Método¿Qué hace?Largo del resultado
.map()Transforma cada elemento.Igual al original.
.filter()Filtra los que cumplen la condición.Menor o igual al original.
.reduce()Acumula todo en un único resultado.Un único valor.
let registros = [
    { patente: "AB123CD", velocidad: 120, km: 150 },
    { patente: "XY987ZW", velocidad: 95,  km: 300 },
    { patente: "MN456GH", velocidad: 135, km: 80 }
];

// 1. MAP: Saco solo las patentes
let patentes = registros.map(v => v.patente);

// 2. FILTER: Solo infractores (> 110 km/h)
let infractores = registros.filter(v => v.velocidad > 110);

// 3. REDUCE: Sumo todos los km (el 0 final es el valor inicial)
let totalKm = registros.reduce((acc, v) => acc + v.km, 0); // 530
🚫 Regla del TP2: Está prohibido usar bucles for o while para procesar la flota. Todo se resuelve encadenando filter, map y reduce.
