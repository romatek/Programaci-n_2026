2. Variables, Tipos de Datos y Coerción

Las variables son cajas con etiqueta donde guardás información:

  • let: Caja que podés abrir y cambiar lo que tiene adentro (ej. let velocidad = 80;).
  • const: Caja con candado. Una vez que guardás algo, no se puede cambiar (ej. const IVA = 0.21;).

Los 5 tipos de datos básicos

  • string: Texto entre comillas ("AB123CD").
  • number: Cualquier número, entero o decimal (120, 45.5).
  • boolean: Solo dos valores: true (verdadero) o false (falso).
  • undefined: Creaste la caja (let x;), pero todavía no guardaste nada.
  • null: Vaciaste la caja a propósito (let x = null;).

El misterio de "5" + 3 (Coerción de tipos)

// Regla 1: El signo + con un texto SIEMPRE une los textos (concatena)
console.log("5" + 3); // "53" (¡No suma 8!)

// Regla 2: Los signos -, *, / convierten todo a número
console.log("5" - 3); // 2
🏆 Regla de oro para comparar: Usá siempre triple igual (=== y !==). Compara el valor Y el tipo de dato. Nunca uses == porque hace conversiones raras (0 == "" da true).
