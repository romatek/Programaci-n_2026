1. ¿Qué es programar? Lógica y Git/GitHub

Programar no es memorizar palabras en inglés, es aprender a resolver problemas paso a paso. La lógica es siempre la misma; JavaScript (JS) es solo el idioma en el que se lo escribimos a la computadora.

Git vs. GitHub (No son lo mismo)

Analogía: Git es la cámara de fotos (guarda el historial en tu PC) y GitHub es Instagram (donde subís las fotos para mostrarlas).
