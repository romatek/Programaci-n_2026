11. Métodos de Arreglos y Objetos Literales

Métodos rápidos de arreglos

  • .includes("x"): Devuelve true o false si está en la lista.
  • .indexOf("x"): Devuelve la posición o -1 si no está.
  • .find(v => v > 110): Devuelve el primer elemento que cumple la condición.
  • .slice(1, 3): Devuelve una copia recortada sin tocar el original.
  • .splice(2, 1): Elimina elementos modificando el original.
  • .sort((a, b) => a - b): Ordena números de menor a mayor.

Objetos Literales ({}) y Arreglos de Objetos

Un objeto agrupa propiedades con nombre (clave: valor). Meter objetos dentro de un arreglo es el patrón estrella de la programación moderna:

let flota = [
    { patente: "AB123CD", velocidad: 120, tipo: "auto" },
    { patente: "XY987ZW", velocidad: 95,  tipo: "camion" }
];

console.log(flota[0].patente); // Accedemos con punto -> "AB123CD"
