4. Práctica de Decisiones y Validación Básica

Si el usuario escribe "veinte" en letras, Number("veinte") devuelve NaN (Not a Number). Para frenar ese error antes de decidir, usamos isNaN():

let altura = Number(prompt("Altura del vehículo:"));

if (isNaN(altura)) {
    console.log("⚠ Error: Ingrese un número válido.");
} else if (altura <= 2.5) {
    console.log("🟢 Puede pasar por el túnel.");
} else {
    console.log("🔴 No pasa: riesgo de impacto.");
}
Cadena vs. Preguntas sueltas: Usás if / else if cuando los caminos son excluyentes (entra en uno solo). Si querés aplicar varios recargos o descuentos acumulables (como calcular un seguro), usás varios if sueltos uno debajo del otro para que se evalúen todos.
