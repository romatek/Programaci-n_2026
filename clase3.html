3. Condicionales: El programa toma decisiones

Cuando pedís un dato con prompt("Velocidad:"), siempre llega como texto (string). Antes de hacer cuentas, tenés que convertirlo manualmente usando Number().

if / else if / else (Para rangos)

JavaScript lee de arriba hacia abajo y entra únicamente en el primer camino verdadero:

let velocidad = Number(prompt("Velocidad:"));

if (velocidad <= 80) {
    console.log("🟢 Normal");
} else if (velocidad <= 110) {
    console.log("🟡 Precaución"); // Si llegó acá, ya sabemos que es > 80
} else {
    console.log("🔴 Riesgo alto");
}

switch (Para valores exactos)

switch (codigoInfraccion) {
    case 1:
        console.log("Exceso de velocidad");
        break; // ¡OBLIGATORIO! Corta el switch para que no siga de largo
    default:
        console.log("Código inválido");
}
