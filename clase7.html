7. Funciones, Scope y Modularización

Una función es una receta con nombre que escribís una vez y llamás todas las veces que necesites para no copiar y pegar código.

function calcularDescuento(monto) { // 'monto' es el parámetro
    return monto * 0.80; // RETURN devuelve el resultado para usarlo afuera
}

let total = calcularDescuento(5000); // Vale 4000
  • console.log() vs. return: console.log solo muestra texto en pantalla. Si querés guardar el resultado en una variable, necesitás return.
  • Scope: Las variables creadas adentro de una función solo existen ahí adentro.
  • Modularizar: Dividir un problema grande en funciones chiquitas donde cada una hace una sola cosa.
