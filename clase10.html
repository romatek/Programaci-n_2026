10. Arreglos (Arrays): Colecciones de Datos

Un arreglo es una lista ordenada que guarda muchos valores en una sola variable usando corchetes [].

¡Regla vital! Las posiciones siempre empiezan a contar desde 0.
let velocidades =;

for (let i = 0; i < velocidades.length; i++) {
    console.log(velocidades[i]);
}

velocidades.push(110); // Agrega AL FINAL
velocidades.pop();     // Saca el ÚLTIMO
